# Requirements Documentation

## Authoritative Specification

The approved BookFlow Minimum Viable Technical Specification (MVTS) is maintained at:

- `docs/specifications/BookFlow_MVTS_v1.1.docx`

Consult this document for the approved product scope, actors, functional requirements, non-functional requirements, constraints, assumptions, and acceptance criteria.

## Requirements Change Control

- Do not silently modify approved requirements.
- Record proposed scope changes for review before implementation.
- Keep implementation and tests traceable to approved requirements where practical.
- If a requirement is ambiguous or conflicts with another authoritative document, record the issue and resolve it explicitly.
- Do not treat design mockups or generated prototype code as authority to expand MVP scope.
