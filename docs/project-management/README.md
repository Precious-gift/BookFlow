# Project Management

This directory maintains project planning, milestones, backlog specifications, engineering rules, and implementation records for BookFlow.

Keep project status factual. Distinguish planned, in-progress, blocked, and completed work. A screen prototype or documentation file alone does not prove that an application feature has been implemented or tested.

## Structure

- [backlog/](./backlog/): Canonical 56-ticket backlog dataset (`backlog_manifest.json`), narrative specification (`BOOKFLOW_MVP_BACKLOG_PACKAGE_v1.0.md`), and public [Trello Board](https://trello.com/b/3BOlXBHK/bookflow-mvp-implementation) integration.
- [ANTIGRAVITY_IMPLEMENTATION_RULES.md](./ANTIGRAVITY_IMPLEMENTATION_RULES.md): Permanent implementation guidelines, architectural boundaries, and AI session instructions.
- [archive/yougile/](./archive/yougile/): Historical Phase 7.2 YouGile planning and CLI tooling evaluation artifacts (superseded by Trello).
